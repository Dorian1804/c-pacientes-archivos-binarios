# Registros en archivos binarios

Programa académico de altas, consultas y edición de registros mediante archivos binarios.

## Requisitos

Compilador C++ (por ejemplo, GCC/MinGW) y terminal. Usa datos ficticios para practicar.

## Ejecutar

Desde esta carpeta:

```powershell
g++ "archivo de lectura y escritura.cpp" -o programa
.\programa.exe
```

Revisa las funciones disponibles en el menú y cierra el programa antes de inspeccionar sus archivos. Algunas funciones pueden depender del entorno Windows original.
